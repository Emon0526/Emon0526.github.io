Remotion vs HyperFrames 命令速查

前置操作：两个工具都需要先执行 unset NODE_OPTIONS

Remotion（React / TypeScript）

核心命令

命令 用途
npx remotion studio src/index.ts 启动预览 Studio（热重载，默认 localhost:3000）
npx remotion render src/index.ts <组合名> out.mp4 渲染为 MP4
npx remotion still src/index.ts <组合名> out.png 渲染单帧截图
npx remotion compositions src/index.ts 列出所有可用组合
npx remotion benchmark src/index.ts <组合名> 性能基准测试
npx remotion bundle src/index.ts 打包为 Web 部署

常用渲染参数

参数 说明 默认值
--fps=30 帧率 30
--codec=h264 编码器 h264
--codec=h265 H.265 编码 —
--codec=vp8 VP8 (WebM) —
--codec=vp9 VP9 (WebM) —
--codec=prores Apple ProRes —
--quality=80 CRF 质量（0-100） —
--scale=0.5 输出缩放比例 1
--jpeg-quality=90 序列帧 JPEG 质量 —
--concurrency=4 并行渲染线程数 CPU 核数
--enforce-audio-track 强制包含音轨 —

倒计时项目渲染示例

HyperFrames（HTML / 声明式）

核心命令

命令 用途
npx hyperframes preview 启动预览 Studio（热重载，默认 localhost:3000）
npx hyperframes render 渲染为 MP4（默认）
npx hyperframes render --format webm 渲染透明通道 WebM
npx hyperframes render --format mov 渲染透明通道 MOV
npx hyperframes render --format png-sequence 渲染 PNG 序列帧
npx hyperframes lint 代码校验（检查常见错误）
npx hyperframes inspect 可视化布局检查
npx hyperframes snapshot 关键帧 PNG 截图
npx hyperframes benchmark 性能基准测试
npx hyperframes doctor 系统依赖检测
npx hyperframes init <项目名> 创建新项目
npx hyperframes compositions 列出项目中所有组合

常用渲染参数

参数 说明 默认值
--fps=30 帧率 30
--format=mp4 输出格式 mp4
--format=webm WebM 透明通道 —
--format=mov MOV 透明通道 —
--format=png-sequence PNG 序列帧 —
--quality=draft 草稿画质（快） standard
--quality=standard 标准画质 ✅
--quality=high 高质量 —
--workers=auto 并行 worker 数 auto
--resolution=1080p 输出分辨率 1080p
--resolution=4k 4K 分辨率 —
--docker Docker 容器化渲染 —
--strict lint 错误时阻断渲染 —
-o out.mp4 指定输出文件路径 自动命名
--variables='{"title":"Hello"}' 传入变量 —

倒计时项目渲染示例

两者对比

维度 Remotion HyperFrames
语言 React + TypeScript HTML + 声明式 data-* 属性
动画引擎 useCurrentFrame() + CSS GSAP + 声明式属性
预览命令 studio preview
渲染命令 render → 指定入口+组合名 render → 自动找 index.html
帧率控制 代码 calculateMetadata() 或 CLI --fps CLI --fps
最少文件数 3-5 个（tsx + config） 1 个 HTML 即可
透明度输出 需额外配置 --format webm/mov 原生支持
云端渲染 Remotion Lambda hyperframes cloud / lambda
热重载 ✅ ✅
版本（本机） remotion 4.0.389 hyperframes 0.6.72

本机注意事项

  • 两个工具运行前都需要 unset NODE_OPTIONS（系统注入了 --use-system-ca，与托管 Node 不兼容）
  • 一劳永逸方案：在 ~/.zshrc 末尾添加 unset NODE_OPTIONS
  • ffmpeg 使用 ~/.local/bin/ffmpeg（静态版 v8.1.1），Homebrew 版（v7.1.1）依赖已损坏但不影响使用
